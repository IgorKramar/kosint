# Реестры России

Здесь берутся факты, которые можно предъявить. Всё остальное в расследовании — сведения,
эти — доказательства.

Полный каталог с ограничениями каждого источника — `references/registries-ru.md`. Читай
его, когда реестр повёл себя не так, как ожидалось, или когда нужен источник, которого
нет в чеклисте.

## Начало

```bash
bash scripts/urls.sh person "<ФИО>" [ДД.ММ.ГГГГ] [регион]   # 37 проверок
bash scripts/urls.sh entity "<ИНН|ОГРН|название>"
```

Вывод — чеклист со ссылками, в которые уже подставлены параметры. Идёшь по нему сверху
вниз, отмечая сделанное.

## Единственный машинный источник

```bash
bash scripts/egrul.sh search 7736207543          # по ИНН
bash scripts/egrul.sh search "Иванов Иван"       # по ФИО, находит ИП
bash scripts/egrul.sh vypiska <токен> out.pdf    # выписка
```

Остальные реестры **не берутся скриптом**: формы, капчи, защита от автоматики. `curl` и
WebFetch возвращают 403 или пустую страницу — это проверено, повторять незачем. Открывай
браузером, отдельной вкладкой, закрывай после.

## Что реестр не отдаёт

**ЕГРЮЛ не отвечает на вопрос о человеке.** Он отвечает на вопрос о компании. Связь
«человек → юрлица, где он учредитель или директор» строят агрегаторы: Rusprofile и Checko
в поиске по персоне. Поэтому они в обязательной части чеклиста, а не в дополнительной.

**Росреестр больше не даёт обратного поиска по недвижимости.** С марта 2023 года ФИО
правообладателя третьим лицам не выдаётся. Указания «проверить недвижимость по ФИО» —
устарели; если встретил такое в чужой инструкции, это признак её возраста.

## Дата рождения обязательна

ФССП, реестр залогов, банкротство и дисквалификация ищут по ФИО с датой рождения. Без
даты они вернут однофамильцев, и записать их результат как результат по субъекту —
худшая ошибка, которую здесь можно совершить.

Нет даты рождения — либо получай её, либо помечай проверку как невыполненную. Третьего
варианта нет.

## Пусто и не проверено — разные вещи

| Запись | Что значит |
| --- | --- |
| «ФССП: открытых производств нет на 12.09.2026» | реестр ответил, записей нет. Это факт, и он идёт в досье |
| «ФССП: не проверено, капча» | мы не знаем |

Второе, записанное как первое, — выдумка с положительным знаком. Она опаснее выдумки с
отрицательным, потому что снимает вопрос вместо того, чтобы его поднять.

Отрицательный результат всегда идёт с датой: производство закрывают вчера, а долг
остаётся.

## Тексты судебных решений

Самый недооценённый источник в рунете. В мотивировочной части суд перечисляет то, чего
нет нигде: адреса, состав семьи, имущество, места работы, суммы. Один найденный акт
нередко даёт больше, чем весь остальной обход.

Ищется на `bsr.sudrf.ru` полнотекстово, по Москве — на `mos-gorsud.ru` по участнику.

## Документы проверяются, а не добываются

Паспорт, диплом, водительское удостоверение проверяются по реквизитам, которые даёт сам
человек. Это штатная процедура при найме и перед сделкой. Попытка получить чужие
паспортные данные — ровно тот состав, ради которого существует ст. 272.1 УК.

## Когда проверок много

Запускай сабагента `registry-walker` — он проходит чеклист и возвращает факты со
ссылками, ничего не интерпретируя. Передавай ему всё известное: без даты рождения и
региона половина проверок бессмысленна.
