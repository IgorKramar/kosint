# KOSINT

Расследование по российскому субъекту устроено не так, как по западному. Основной объём
проверяемых фактов дают государственные реестры, а не соцсети; поиск идёт через Яндекс, а
не Google; главный идентификатор — ИНН, а не имя. Плагин построен вокруг этого.

## Порядок

Фазы идут по очереди. Пропуск первой обесценивает остальные.

### 1. Основание

**До первого запроса** назови, зачем собираются сведения и на каком основании. Проверка
контрагента перед сделкой, согласие кандидата, законный интерес, собственная экспозиция —
формулировка идёт в шапку журнала и в досье.

Основания «клиент попросил» и «интересно» не существуют. Если пользователь не назвал
своё — спроси один раз и не начинай без ответа. Подробности и границы —
`references/law-ru.md`.

### 2. Журнал

```bash
bash scripts/kosint.sh init "<Субъект>" "<основание>"
```

Путь из вывода — рабочий файл расследования. Каждый установленный факт пишется туда сразу:

```bash
bash scripts/kosint.sh fact <журнал> A "ИП с 2019 года, ОГРНИП 319…" "ЕГРИП, запрос 12.09.2026"
```

Факт без источника в журнал не принимается. Это не формальность: досье без источников
выглядит точно так же, как досье с источниками, и разница обнаруживается, когда на него
уже сослались.

### 3. Предоставленные материалы

Если заказчик расследования приложил файлы — экспорт переписки, письма, документы,
скриншоты, выгрузку CRM, — они разбираются **здесь, до внешнего обхода**.

```bash
python3 scripts/chatlog.py <файл> --quotes 5
```

Переписка с человеком плотнее любого внешнего источника: она не отредактирована под
аудиторию, датирована, и в ней человек сам называет телефон, почту, ИНН, место работы и
окружение. Половина запросов к реестрам после её разбора оказывается ненужной, а другая
половина — уточнённой.

Экспорт целиком не читается: файл на тысячи сообщений вытеснит из контекста само
расследование. Скрипт снимает механический слой, читаются сводка и цитаты.

**Различай два факта.** «Он сообщил, что работает директором» — грейд A, переписка это
доказывает. «Работает директором» — грейд B, пока не подтвердит ЕГРЮЛ: в переписке врать
проще, чем в реестре. Расхождение между сказанным и записанным — находка, а не помеха.

Переписка не общедоступный источник. Основание на неё называется отдельно, дословные
цитаты не покидают досье, третьи лица из чата в досье попадают только по делу.
Подробности — скилл `kosint:materials`.

### 4. Опознание

Задача фазы — получить **второй идентификатор** сверх имени. ФИО в России не
идентификатор: «Иванов Иван Иванович» даёт в ЕГРИП больше шестисот тысяч совпадений.

Годятся ИНН, ОГРНИП, дата рождения, ник, телефон, почта, место работы с городом. Пока
второго идентификатора нет, всё найденное — кандидаты, а не факты. Таблица переходов —
`references/pivots.md`.

### 5. Обход

Два направления независимы, поэтому идут параллельно — сабагентами, в одном сообщении:

- **`registry-walker`** — государственные реестры. Список проверок даёт
  `bash scripts/urls.sh person "<ФИО>" [дата рождения] [регион]`.
- **`footprint-hunter`** — цифровой след: ники, площадки, публикации, контакты.

Обоим передаётся **всё**, что уже известно, и оба возвращают факты со ссылками, без
выводов. Выводы делает эта сессия, имея обе картины разом.

Детали каждого направления — скиллы `kosint:registry` и `kosint:footprint`. Читай их,
когда ведёшь направление сам, а не поручаешь.

### 6. Сведение

Каждый факт получает грейд:

| Грейд | Когда |
| --- | --- |
| **A** | государственный реестр либо два независимых источника |
| **B** | один заслуживающий доверия источник |
| **C** | вывод по косвенным признакам: часовой пояс, геометка, окружение |
| **D** | единичное непроверенное упоминание |

Два агрегатора, переписывающих один ЕГРЮЛ, — **один** источник. Независимость означает
разную природу: реестр, судебный акт, публикация, переписка.

Противоречия не разрешаются молча. Если в одном месте «директор», в другом
«соучредитель» — в досье идут оба варианта со ссылками и пометкой о расхождении.

### 7. Профиль

Скилл `kosint:profile`. Строится по цитатам, а не по впечатлению. MBTI и зодиак не
используются — хук плагина не пропустит их в файл.

### 8. Проверка

Сабагент `skeptic` читает собранное и ищет, чем оно неверно. Запускается **до** выдачи, а
не после вопроса пользователя. Находки закрываются или переносятся в раздел «не
проверено».

### 9. Досье

Скилл `kosint:dossier`. Файл ложится в `60-people/` рабочего vault по шаблону
`assets/dossier-template.md`.

## Когда останавливаться

Числового порога готовности здесь нет намеренно: взвешенная сумма субъективных оценок
даёт ложную точность, а порог по ней — разрешение остановиться, когда цифра сошлась.

Вместо этого — три вопроса:

1. **Личность подтверждена?** Есть хотя бы один факт грейда A, привязывающий субъекта к
   идентификатору. Нет — расследование не закончено, чем бы ни был заполнен файл.
2. **Вопрос, ради которого собиралось, закрыт?** Досье отвечает на конкретный вопрос.
   «Собрали всё» — не ответ.
3. **Непроверенное названо?** Раздел «не проверено» заполнен и честен.

Если на все три «да» — досье готово, сколько бы в нём ни было строк. Если «нет» хотя бы
на первый — так и скажи, а не компенсируй объёмом.

## Чего не делается

Вход в чужие аккаунты, обращение к человеку или его окружению под легендой, заявки в
друзья, сбор сведений о здоровье, вере и интимной жизни, слежка в реальном времени, сбор
данных о несовершеннолетних.

Сервисы, торгующие слитыми базами, блокируются хуком `probiv-guard`. Знать об этом надо
до вызова: получение таких данных — состав по ст. 272.1 УК, и отвечает получатель.
Легальная замена по тем же вопросам — реестры.

## Инструменты

| Команда | Что делает |
| --- | --- |
| `scripts/kosint.sh init\|fact\|status` | журнал расследования |
| `scripts/egrul.sh search\|vypiska` | ЕГРЮЛ и ЕГРИП, единственный реестр с машинным доступом |
| `scripts/urls.sh person\|entity\|nick\|phone\|email` | чеклист готовых ссылок с подставленными параметрами |
| `scripts/chatlog.py <файл>` | разбор предоставленной переписки: идентификаторы, ритм, речь |

Остальные реестры живут за формами и капчами: `curl` и WebFetch дают на них 403 либо
пустую страницу. Штатный инструмент для них — браузер.
