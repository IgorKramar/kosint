# Переходы: что из чего получается

Расследование движется не по списку площадок, а по идентификаторам. Каждый найденный
идентификатор открывает следующий слой. Площадка, до которой не дотянулся ни один
идентификатор, даёт однофамильцев, а не человека.

Эта таблица — рабочий инструмент, а не иллюстрация. Застрял — посмотри, какой
идентификатор у тебя на руках, и возьми строку.

## Сила идентификаторов

Не все входные данные равны. По убыванию полезности:

| Идентификатор | Что открывает | Насколько уникален |
| --- | --- | --- |
| **ИНН** | все налоговые реестры, самозанятость, ИП, связи с юрлицами | однозначен |
| **ОГРНИП / ОГРН** | реестр целиком, выписка, история изменений | однозначен |
| **ФИО + дата рождения** | ФССП, банкротство, залоги, суды | почти однозначен |
| **Ник** | соцсети, форумы, код, геймерские площадки | обычно однозначен |
| **Телефон** | мессенджеры, объявления, подписи в чужих книгах | однозначен, но закрыт |
| **Почта** | утечки, Google-аккаунт, коммиты, регистрации | однозначен |
| **Фотография** | другие профили с тем же аватаром | сильно зависит от площадки |
| **ФИО** | ничего само по себе | «Иванов Иван Иванович» — 600+ тысяч ИП |

**Главное следствие.** Если на входе только ФИО, первая задача — не искать человека, а
получить второй идентификатор. Пока его нет, любая найденная запись остаётся кандидатом.

| ОГРН компании | руководитель и учредители | `egrul.sh search <ОГРН>`, затем выписка |

| Почта | ник | локальная часть адреса — это и есть ник, прогони её по площадкам |

| Телефон | имя | импорт контакта в Telegram, GetContact, объявления на Авито |
| Фото | другие профили | Яндекс.Картинки для рунета, Search4Faces для ВКонтакте и Одноклассников |
| Профиль ВКонтакте | окружение | друзья, отметки на фото, комментарии, общие группы |
| Профиль ВКонтакте | город и возраст | поля профиля, но сверяй: они заполняются как попало |

| Госзакупка | связи между людьми | кто подписывал контракт, кто был вторым участником |

## Правило второй привязки

Факт переносится из одного источника в другой, только если есть **два независимых
совпадения**. Одно — имя. Второе — что угодно проверяемое: город, работодатель, редкое
отчество, фотография, упомянутый проект, общий знакомый.

Без второй привязки запись остаётся в списке кандидатов. Смешение однофамильцев — самая
дорогая ошибка в этой работе, потому что досье после неё выглядит цельным: внутренних
противоречий нет, ведь про каждого из двух людей всё сходится.

## Когда след неожиданно пуст

Человек, который должен быть заметен, не находится — это само по себе наблюдение, а не
тупик. Проверь в таком порядке:

1. **Яндекс, а не Google.** Кэш рунета живёт у него дольше.
2. **Wayback Machine** по предполагаемым адресам профилей — удалённое остаётся в копии.
3. **Транслитерации и опечатки** — Ivanoff, Ivanow, латиница вперемешку с кириллицей.
4. **Девичья фамилия**, если речь о женщине и есть признаки замужества.
5. **Архивы конференций и вузов** — биографии докладчиков переживают удалённые профили.
6. **Вывод о самом человеке.** Пустой след у публичной фигуры означает либо
   целенаправленную гигиену, либо что вы ищете не то имя.
