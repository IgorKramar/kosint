# KOSINT

OSINT-расследования по людям и организациям с упором на Россию.

Плагин для Claude Code. Ядро — государственные реестры, а не соцсети: по российскому
субъекту они дают основную массу проверяемых фактов, и именно их не хватает
универсальным OSINT-инструментам.

## Чем отличается

**Реестры в основе.** Тридцать семь проверок по физическому лицу и одиннадцать по
организации, от ЕГРИП и ФССП до реестра дипломов Рособрнадзора и перечня
Росфинмониторинга. Со ссылками, в которые уже подставлены параметры поиска.

**Браузер вместо скраперов.** Российские реестры живут за формами и капчами: `curl` на
них отвечает 403. KOSINT открывает их браузерной автоматизацией, а скриптом берёт только
то, что действительно отдаётся машинно.

**У факта есть источник и дата.** Журнал расследования не принимает строку без ссылки, а
хук не пропускает досье, где факт остался без источника или грейда достоверности.

**Заслон против «пробива».** Обращения к сервисам, торгующим слитыми базами, блокируются
на уровне инструмента. Получение таких данных — состав по ст. 272.1 УК РФ, и отвечает в
том числе получатель.

**Без MBTI и зодиака.** Поведенческий профиль строится по наблюдаемым признакам речи и
поступков. Четыре буквы типологии выглядят как измерение, не будучи им, и поэтому в файл
не попадают.

## Установка

```
/plugin marketplace add IgorKramar/kosint
/plugin install kosint@kosint
```

Зависимости: `jq`, `python3`, `curl`. Для реестров за формами — браузерная автоматизация
Claude in Chrome.

## Скиллы

| Скилл | Для чего |
| --- | --- |
| `kosint` | полный цикл: основание, журнал, обход, сведение, проверка, досье |
| `kosint:registry` | государственные реестры России |
| `kosint:footprint` | цифровой след: ники, площадки, почта, телефон, архивы |
| `kosint:profile` | поведенческий профиль по собственным текстам человека |
| `kosint:dossier` | сборка досье и запись карточкой в vault |
| `kosint:selfcheck` | разведка по себе: что видно снаружи и что с этим делать |

## Агенты

| Агент | Роль |
| --- | --- |
| `registry-walker` | обходит реестры, возвращает факты со ссылками, не интерпретирует |
| `footprint-hunter` | ищет сетевой след, возвращает ссылки и цитаты |
| `skeptic` | состязательная проверка досье: однофамильцы, выводы шире доказательств |

Первые два работают параллельно: направления независимы.

## Инструменты

```bash
scripts/kosint.sh init "Иванов И. И." "проверка контрагента"   # журнал
scripts/kosint.sh fact <журнал> A "факт" "источник"
scripts/kosint.sh status <журнал>

scripts/egrul.sh search 7736207543              # ЕГРЮЛ и ЕГРИП, JSON
scripts/egrul.sh vypiska <токен> out.pdf

scripts/urls.sh person "Иванов Иван" 01.01.1980 77
scripts/urls.sh entity 7736207543
scripts/urls.sh nick|phone|email <значение>
```

## Хуки

| Хук | Событие | Что делает |
| --- | --- | --- |
| `probiv-guard` | PreToolUse | блокирует обращения к сервисам торговли утечками |
| `dossier-gate` | PostToolUse | не пропускает досье без источников, грейдов и основания |

## Границы

Плагин работает только с законно доступным. Вход в чужие аккаунты, обращение под
легендой, сбор сведений о здоровье и вере, слежка, данные о несовершеннолетних — вне
его назначения, и это не настраивается.

Сбор сведений о человеке из открытых источников остаётся обработкой персональных данных
по 152-ФЗ и требует названного основания. KOSINT спрашивает его до первого запроса и
пишет в досье. Разбор — `references/law-ru.md`.
